A full-stack web application for managing an artisanal ice cream inventory. Built with a **FastAPI** REST backend, **SQLAlchemy** ORM with SQLite, and an interactive **Beige & Brown themed** HTML/CSS/JS frontend.

---

## ✨ Features

* 🍦 **Complete CRUD Operations**: Create, read, update, and delete ice cream flavors.
* 🔍 **Smart Filtering**: Filter items instantly by maximum price or flavor type (*Chocolate, Vanilla, Caramel*).
* 🎨 **Aesthetic UI**: Custom warm-themed parlor UI built with modern CSS grid & flexbox.
* ⚡ **Fast & Lightweight**: Built without heavy frontend frameworks—pure JavaScript `fetch` API.

---

## 🛠️ Tech Stack

* **Backend**: FastAPI, Python
* **Database & ORM**: SQLite, SQLAlchemy
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
